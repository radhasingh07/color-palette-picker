# 🎨 Color Palette Picker

A responsive Color Palette Picker built using HTML, CSS, and JavaScript. This application allows users to explore, generate, and copy beautiful color palettes, making it a useful tool for web developers, UI/UX designers, and graphic designers.

## ✨ Features

- Generate random color palettes
- Display HEX color codes
- Copy color codes with one click
- Responsive design
- Clean and modern user interface
- Easy-to-use layout

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)

## 📂 Project Structure

```
Color-Palette-Picker/
│── index.html
│── style.css
│── script.js
│── locked and copied.png
│── save.png
└── README.md
```

## 🚀 How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in your web browser.

## 🎯 Use Cases

- Find attractive color combinations
- Copy HEX color codes for websites
- Create color palettes for UI/UX projects
- Use colors in web and graphic design
